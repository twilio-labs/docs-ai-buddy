# Generate Alt Text Prompt

## Prompt

```
Create concise alt text for images in technical documentation by extracting essential text and describing key elements.

- Focus on useful, information-rich content using appropriate keywords.
- Ensure alt text is less than 125 characters.
- Identify specific image types like logos, illustrations, or cartoons.
- Avoid duplicating adjacent text.
- End the alt text with a period.
- Do not use semicolons.

# Steps

1. Extract text from the image.
2. Identify key elements to highlight.
3. Construct a concise, information-rich alt text sentence.
4. Ensure the alt text is under 125 characters and adheres to the guidelines.

# Output Format

Alt text should be a single sentence, ending with a period, and less than 125 characters long.

{{imagePath}}
```

## OpenAI API Parameters

Retry Attempt:
- Model: gpt-4o
- Temperature: 0.3 (reduced for more focused output)
- Max Tokens: 50 (reduced to encourage brevity)
- Additional Instructions: "IMPORTANT: The previous response was too long. Please create a shorter, more concise alt text under 125 characters."

### Retry Mechanism Notes
**Strategy:** Adaptive retry with intelligent fallback

1. First Attempt: Uses standard parameters with full creative freedom (temperature=1, max_tokens=256)

2. Length Check: After receiving response, validates that alt text ≤ 125 characters

3. Retry Trigger: If length > 125 characters:
    - Logs warning with actual length
    - Makes ONE retry attempt (cost control: max 1 retry)
      - Adjusts parameters to encourage brevity:
      - Lower temperature (0.3) for more deterministic output
      - Reduced max tokens (50) to limit response length
      - Appends explicit instruction about the length requirement
4. Final Fallback: If retry still produces text > 125 characters:
    - Logs second warning
    - Intelligently truncates to 125 characters:
      - Finds last complete word before character 122
      - If last space is after position 100, uses that boundary
      - Adds ellipsis (...) to indicate truncation
      - Otherwise truncates at 122 and adds ellipsis

**Cost Optimization:** Limited to 1 retry attempt to prevent excessive API costs while still improving accuracy.

### Failure Modes

- **Exceeding Character Limit**: May generate alt text that exceeds the 125 character limit, requiring truncation.
- **Missing Critical Information**: Might focus on less important visual elements while missing the core purpose of the image.
