# Generate Metadata Prompt

## Full Metadata Generation Prompt (Title and Description)

```
Role: SEO Expert & Documentation Engineer. Generate high-converting, search-optimized metadata.

Input Content: 
{{content}}
{{additionalContext}}

STEP 1: SEMANTIC ANALYSIS
Consider for your writing:
- Search Intent: Informational / How-to/Technical / Reference
- Primary Keyword: Most important technical entity or action
- Target Audience: Developers / DevOps / Business Decision Makers

STEP 2: REQUIREMENTS

Meta Title:
* Format: [Keyword Phrase] | [Product/Brand Name]
* Max 55 characters
* Must not start with brand names

Meta Description:
* Length: 140-155 characters
* Active voice with action verb (Learn, Build, Configure, Deploy, Integrate, etc.)
* Primary keyword in first 60 characters
* Don't repeat title verbatim
* Include specific benefits/features and secondary keywords

STEP 3: STYLE CONSTRAINTS
* No exclamation points
* Avoid: leverage, easy, simple, seamless, revolutionary, power, unlock, ultimate
* Tone: Factual, objective, utility-driven (no marketing fluff)

STEP 4: OUTPUT FORMAT
Provide exactly 3 distinct samples with character counts in parentheses.

Option 1:
Title: [Your Title] (XX characters)
Description: [Your Description] (XXX characters)

Option 2:
Title: [Your Title] (XX characters)
Description: [Your Description] (XXX characters)

Option 3:
Title: [Your Title] (XX characters)
Description: [Your Description] (XXX characters)
```

### Evaluation Notes

#### Edge Cases

- **Very Technical Content**: Focus on clarity while maintaining accuracy of technical concepts.
- **Multiple Key Topics**: Prioritize the most important aspects for the metadata.
- **Very Short Content**: Extract the core value proposition without embellishment.
- **Content with Code Examples**: Focus on the purpose of the code rather than specific implementation details.
- **Complex Procedures**: Break down into digestible core action and benefit in the metadata.

#### Failure Modes

- **Exceeding Character Limits**: May generate titles or descriptions that exceed the specified character limits.
- **Brand Name Starting**: May incorrectly begin titles with brand names despite instructions.
- **Generic Descriptions**: Sometimes produces vague descriptions that don't capture the unique value of the content.
- **Keyword Stuffing**: May overload metadata with keywords at the expense of readability.
- **Missing Key Value Propositions**: Might focus on secondary aspects while missing the primary purpose of the content.

#### Improvement Suggestions

1. Add keyword targeting option to focus metadata on specific search terms.
2. Include competitor analysis to differentiate content positioning.
3. Implement A/B testing capability with multiple metadata variants.
4. Add support for localization considerations in different markets.
5. Create domain-specific optimizations (API docs vs. tutorials vs. reference guides).
